pkg-installer

在 Arch 上装 .deb / .rpm / .AppImage / .flatpak，免 root，不污染 pacman 数据库。

这是一个 pacman 仓库。加进去之后，它就和官方库里的包一样，能用 pacman -Syu 一起升级。

加仓库

# /etc/pacman.conf 末尾追加
[pkg-installer]
Server = https://aceared0829.github.io/pkg-installer/x86_64

# 然后
sudo pacman -Sy
sudo pacman -S pkg-installer
仓库没有签名。不想改 SigLevel 的话，直接下包安装也一样：
sudo pacman -U https://aceared0829.github.io/pkg-installer/x86_64/pkg-installer-2.2.0-1-any.pkg.tar.zst

或者装进 ~/.local，完全不用 root

curl -fsSL https://raw.githubusercontent.com/Aceared0829/pkg-installer/main/install.sh | bash

它做三件事

先告诉你有没有更好的办法。拿到包先搜 pacman 官方库和 AUR，搜到了就亮黄条，附一条可以直接粘的命令。用原生包意味着以后 pacman -Syu 就能升级。

把依赖名翻译成 Arch 的。deb 写包名、rpm 写 soname，两张表分开翻。缺什么就红条列出来，附 sudo pacman -S --needed ...。不认识的名字单独归类，不假装「依赖齐全」。

解包、链接、导图标，全程不要 root。装进 ~/.local/opt/<包名>/，链一条命令、写一个桌面条目。卸载就是删掉那个目录和几条软链。
